# Variant Caller Skill

## Metadata
- Name: variant-caller
- Description: Skill for variant calling from BAM files using bcftools and freebayes.
- Version: 1.0
- Authors: liuliuliuliullll
- License: MIT

## Documentation
This skill allows users to perform variant calling on BAM files. It supports multiple callers including bcftools and freebayes, and generates VCF output with quality filtering. Additionally, it includes a reproducibility bundle with necessary commands and dependencies for running the skill.
